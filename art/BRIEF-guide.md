# BRIEF：島民引導者半身立繪（guide/，9 張）

網站在新手導覽和登島簡介時，會在對話框旁邊放一位島民的半身立繪。
- 電腦和投影：畫面左下角，約 200 px 高。
- 手機（約 340 px 寬的畫面）：縮小放在對話框的左上角，約 88 px 高。所以線條要粗、形狀要簡單，88 px 時臉和手勢仍要看得懂。

三位島民都是本站原創角色，已經有 96×96 的頭像：`folk/surveyor.svg`、`folk/storyteller.svg`、`folk/chief.svg`。半身立繪要和頭像是同一個人（同樣的臉、帽子或髮型、眼鏡、衣服顏色、招牌道具），畫風也要一樣。不要模仿任何現有遊戲或動畫的角色。

## 一定要照做的要求

1. 只建立這 9 個檔案（放在 `guide/`）：
   - `surveyor-idle.svg`、`surveyor-point.svg`、`surveyor-cheer.svg`
   - `storyteller-idle.svg`、`storyteller-point.svg`、`storyteller-cheer.svg`
   - `chief-idle.svg`、`chief-point.svg`、`chief-cheer.svg`
2. 格式：
   - 根元素 `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 160 200">`，不要設 width / height。
   - 不能有 `<text>`、`<title>`、註解、`<style>`、script、href；元素只用 g path circle ellipse rect line polyline polygon。
   - 每個檔案不超過 7 KB。
   - 顏色只能用 `none` 或下面這些變數。立繪一律用固定的淺色顯示（深色主題也不變），實際顏色如下：

     | 變數 | 顏色 | 用途建議 |
     | --- | --- | --- |
     | `var(--fig-ink)` | #3b2a20 深棕 | 外框線、眼睛、深色頭髮 |
     | `var(--fig-paper)` | #fffaf3 米白 | 襯衫、紙、指南針面 |
     | `var(--fig-sand)` | #e9cf9c 膚色／沙色 | 皮膚、帽子、卷軸、扇子 |
     | `var(--fig-warm)` | #f4b26b 暖橘 | 臉頰（fill-opacity .5）、圍巾、徽章、慶祝的小星光 |
     | `var(--fig-soft)` | #9a8f86 灰 | 里長的灰髮和眉毛 |
     | `var(--fig-land)` #9fd08a、`var(--fig-cool)` #cfe6f6、`var(--fig-sea)` #a9d8e6、`var(--fig-deep)` #5ea9c0、`var(--fig-line)` #e6d9c6 | | 地圖等小細節，可用可不用 |
     | `var(--ic)` | 科目色：地理 #1a8aa0、歷史 #b8452a、公民 #6a4bb0 | 衣服主色、帽帶、道具重點色 |

3. 畫法和頭像一致：
   - 整張圖包在一個 `<g fill="none" stroke="var(--fig-ink)" stroke-width="3" stroke-linecap="round" stroke-linejoin="round">` 裡，平塗色塊加深棕外框，不用漸層和陰影。
   - 眼睛是實心小圓點（慶祝姿勢改成笑彎的弧線 ^ ^），臉頰是兩個 `var(--fig-warm)`、`fill-opacity=".5"` 的圓，沒有外框。
4. 構圖：
   - 半身：頭的中心約在 (80, 60)，頭半徑約 30；肩膀約在 y=105；身體一路畫到下緣 y=200 並被切掉（下面不用畫腳）。
   - 上、左、右各留約 6 的邊，舉起的手和帽緣不能超出 viewBox。
   - 角色正面、身體稍微朝向畫面右邊（對話框在右邊）。
5. 同一位角色的三張圖：頭、臉型、髮型或帽子、衣服、比例都要一模一樣（頭部的程式碼可以直接複製），只改手臂、手、道具位置和表情。
6. 三種姿勢：
   - `idle`（一般）：雙手放低，拿著招牌道具在胸前或身側，微笑。
   - `point`（指路）：畫面右側的那隻手臂往右上方伸直（約 45 度），食指指向右上方；另一隻手拿道具。嘴巴是小小張開的笑。
   - `cheer`（慶祝）：兩隻手臂往上舉成 V 字，眼睛笑彎成弧線，嘴巴張開大笑，道具舉高；手邊加 3～4 個小星光（四角星或短線，`var(--fig-warm)`）。
7. 三位角色的特徵（照頭像）：
   - **測量員阿嶺**（`surveyor`，地理）：寬邊沙色帽子，帽帶用 `--ic`；`--ic` 色的工作外套，中間露出米白襯衫，胸前兩個小方形口袋。道具：捲起來的地圖（沙色圓筒、米白筒口）和指南針（米白圓面、`--ic` 指針）。`cheer` 可以一手舉指南針、一手舉攤開的小地圖（`--fig-cool` 底、`--fig-land` 陸地塊）。
   - **說書人卷卷**（`storyteller`，歷史）：深色短髮（`--fig-ink`），頭頂一撮翹起的捲毛；圓框眼鏡（兩個圓加中間鼻樑）；暖橘圍巾；`--ic` 色長袍，前襟兩條暖橘色寬邊。道具：攤開的卷軸或書（沙色，兩端米白捲筒，上面兩三條墨線）和摺扇（沙色扇面加墨色扇骨）。`point` 用合起來的摺扇指向右上方。
   - **里長阿民**（`chief`，公民）：灰色蓬鬆頭髮（`--fig-soft`，兩側較多），灰色眉毛；`--ic` 色外套、米白襯衫；左胸一枚暖橘圓形徽章。道具：大聲公（米白喇叭筒，`--ic` 的喇叭口和握把）。`cheer` 一手高舉大聲公。
8. 完成後在 `art/` 資料夾執行 `python -I check_svg.py guide`，全部要通過。

## 可以調整的版面建議

- 座標、手臂角度、道具的確切形狀和大小都可以自己調整，只要 88 px 高時看得清楚。
- 衣服的皺褶、口袋、扣子等細節可多可少。
- 星光的數量和位置可以調整。

## 放不下時的優先順序

檔案快超過 7 KB 或畫面太擠時，依序保留：
1. 臉和表情
2. 整體輪廓和手勢（指路的方向一定要清楚）
3. 招牌道具
4. 衣服細節（最先刪）

## 範例

- 畫風、線條粗細、配色和臉的畫法：照 `folk/surveyor.svg`、`folk/storyteller.svg`、`folk/chief.svg`（已核可）。
- 目視標準：手機約 340 px 寬的畫面上，立繪約 88 px 高。
