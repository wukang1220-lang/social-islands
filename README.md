# 社會科島嶼

國中社會科（地理、歷史、公民）的複習網站。三科共 35 座島、245 節，每節有重點整理、練習題，部分章節另有圖解和互動小工具；也有集章、島嶼星等、博物館、營地、島民任務、雙人對戰等遊戲化設計。

- 章節依國中社會課本（115 學年度）整理；每一節的重點、練習題和圖解都由本站撰寫、繪製。
- 學習紀錄只存在使用者這台裝置的瀏覽器，不會上傳。換裝置或換網址時，用網站裡的「進度碼」匯出、匯入。

## 網站

`docs/index.html` 是建好的完整網頁，由 GitHub Pages 從 `docs/` 資料夾發布。整個網站只有這一個檔案（字型從 Google Fonts 載入）。

## 資料夾

| 路徑 | 內容 |
| --- | --- |
| `structure.json` | 三科的島嶼、章、節（年級 七上～九下） |
| `content/{geo,his,civ}-{1..6}.json` | 每一節的重點 `k` 和練習題 `q`；`1`～`6` 依序是七上～九下 |
| `extras.json` | 每一節要附的圖解 id 和互動小工具 |
| `museum.tsv` | 每一節的博物館展品（一節一行，順序同 `structure.json`） |
| `qbase.json` | 舊版每節的題數，用來保留學生已得的章 |
| `islands-meta.json` | 島名、標語、顏色 |
| `art/isles/` `art/figs/` `art/icons/` `art/folk/` | 島嶼徽章、圖解、圖示、島民 SVG |
| `art/check_svg.py` | SVG 檢查（只能用指定的顏色變數，不可有 script 或連結，文字不可重疊） |
| `art/BRIEF-*.md` | 各批圖檔的繪製說明 |
| `tpl.html` | 頁面樣板（版面、樣式、程式） |
| `build.py` | 建置程式 |

## 建置

需要 Python 3。

```bash
python -I build.py
```

會寫出兩個檔：

- `../social-islands.html`：發布到 claude.ai artifact 用（不含 `<!doctype>`，由 artifact 加上外框）。
- `docs/index.html`：GitHub Pages 用的完整網頁。

`python -I build.py <檔名>` 會再多寫一份本機預覽檔。

## 內容格式

```json
{"<節 id>": {"k": ["重點，**紅字關鍵詞**用兩個星號包起來"],
             "q": [["題幹", ["選項A", "選項B", "選項C", "選項D"], 0, "解析"]]}}
```

- 每節 10～15 點重點，每點 1～2 個紅字詞，6 題練習題。答案寫第幾個選項（從 0 算）；建置時會依固定亂數打散選項順序。
- **新題目只能加在最後，不要刪除或重排**：學習紀錄以「節 id + 題號」記錄，重排會讓學生的作答紀錄對錯題。
- 紅字標記 `**` 必須成對，兩個紅字詞之間要有其他文字隔開。
